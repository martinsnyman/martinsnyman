## Featured projects

### [RAG Agent Demo](https://github.com/martinsnyman/RAG_agent_demo)
An AI agent that answers questions about a South African small-business tax guide. It uses **retrieval-augmented generation** over a Chroma vector store, with optional **web search** (Tavily), **page scraping** (Playwright) and **email delivery** (Resend), all in a Gradio UI.
`Python` `LangChain` `OpenAI` `Chroma` `Gradio`

### [Merklerex: Crypto Exchange Simulator](https://github.com/martinsnyman/merklrex_crypto_trader)
A console crypto exchange in **C++17** that replays **1M+ real order-book entries** across five trading pairs. It includes a price-priority **matching engine**, user accounts, persistent wallets and OHLC candlestick summaries.
`C++17` `STL` `OOP` `File I/O`

### [Iron Forge Events](https://github.com/martinsnyman/event_handler)
A full-stack **event booking app** with organiser and attendee portals: create and publish events, sell two ticket types, prevent double bookings, and look up or cancel bookings. Data integrity is enforced in the SQLite schema.
`Node.js` `Express` `EJS` `SQLite`

### [Music Visualiser](https://github.com/martinsnyman/music_visualizer)
A browser-based visualiser that runs an **FFT** on music in real time and drives **eight switchable visualisations**, from a spectrum analyser to bass-reactive pulsing circles.
`JavaScript` `p5.js` `p5.sound`
